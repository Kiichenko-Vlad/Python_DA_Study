# 🐍 Python — Домашні завдання

Цей репозиторій містить мої **домашні завдання з Python**, які виконуються в межах навчального курсу [Data Loves Academy](https://www.dataloves.academy/).  
Навчання структуроване **по модулях**, і кожен модуль містить окремі домашні завдання.

Репозиторій використовується для:
- практики програмування на Python для DA
- закріплення навчального матеріалу
- перевірки виконаних завдань викладачами
- формування навчального GitHub-портфоліо

---

## 🎯 Мета репозиторію

- Засвоїти базові та подальші концепції Python для DA
- Навчитися писати чистий, структурований код
- Практикувати роботу з Git та GitHub
- Відстежувати прогрес навчання по модулях

---
